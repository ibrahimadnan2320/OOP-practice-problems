# OOP Practice Problems

A collection of Object-Oriented Programming (OOP) practice programs and exercises in C++.

## Practice Programs

- **`hello_world.cpp`**: Basic introductory "Hello World" program.
- **`Task 1.cpp`**: Calculates the diameter and area of a circle based on user-entered radius using separate functions.
- **`Task2.cpp`**: Checks whether a user-entered number is even or odd using a function.
- **`ALI practice.cpp`**: Even and odd number checker using a function with custom return values.
- **`Untitled1kfkndknf.cpp`**: Compact version of the custom return value even/odd number checker.
- **`Untitled1.cpp`**: C++ starter boilerplate file.
- **`Uzair Arslan Class # 1.cpp`**: Practice on for-loops, while-loops, and core C++ conceptual notes.
- **`OOP Lab Class 2.cpp`**: Introduction to encapsulation, class structure, public/private access specifiers, and getter/setter methods.
- **`Personal Practice # 1 (25-10-26).cpp`**: Multi-class structure (`StudentInfo`, `student_gender`, `exam_marks`) with encapsulation, accessors, and marks validation.
- **`Personal Practice # 1 (26-10-26).cpp`**: Getter and setter methods implementation for private member encapsulation in an age class.
- **`27-10-26 Practice Constructor (Default + Parameterizes).cpp`**: Practice on class member functions, accessor methods, and conceptual notes on constructors and constructor overloading.
- **`question by mam in class.cpp`**: Array of `Student` objects demonstrating default & parameterized constructors, getters/setters, and formatted output.
- **`uzair bhai 5-11-2026.cpp`**: `phone` class demonstrating default constructor, parameterized constructor, copy constructor, and friend function accessing private members.
- **`Personal practice 5-11-26.cpp`**: Real-world API simulation with a `UserAccount` class demonstrating password encapsulation and buffer length validation.
- **`Question 1.cpp`**: Assignment 1 - `SecuritySystem` class featuring manual char-array string processing, validation for security code length and camera counts, and system status retrieval.
- **`Question 2.cpp`**: Assignment 1 - `GameCharacter` class demonstrating default constructor, parameterized constructor, and copy constructor in a game context.
- **`Question 3.cpp`**: Assignment 1 - `SecretAgent` class utilizing a `friend` function `compareAgents` to compute weighted scores and determine mission competition outcomes.
- **`1st quiz pracitce.cpp`**: Array reversal algorithm using pointer parameter (`int* arr`) and pointer arithmetic without index bracket notation.
- **`program1.cpp`**: Refined solution for Assignment 1 (Q1) - `SecuritySystem` with strictly numeric security-code validation and robust char array handling.
- **`program 2.cpp`**: Refined solution for Assignment 1 (Q2) - `GameCharacter` implementing default, parameterized, and copy constructors with interactive player input.
- **`program 3.cpp`**: Refined solution for Assignment 1 (Q3) - `SecretAgent` with dynamic user input and an external `friend` function calculating and comparing total scores.
- **`quiz oop theory practice.cpp`**: Function (`countFrequency`) to search and count the occurrences of a target element in an integer array.
- **`oop lab quiz practice.cpp`**: `session` class constructor practice covering default, parameterized, and copy constructor implementation.
- **`oop lab quiz practice 2.cpp`**: Implementation of a `friend` function modifying and printing private class members of a `male` class object.
- **`class uzair bhai 12-11-2026.cpp`**: In-class lab exercise demonstrating arrays as data members within a class and arrays of objects with nested traversal.
