# OOP Practice Problems

A collection of Object-Oriented Programming (OOP) practice programs and exercises in C++.

## Practice Programs

- **`hello_world.cpp`**: Basic introductory "Hello World" program.
- **`Task 1.cpp`**: Calculates the diameter and area of a circle based on user-entered radius using separate functions.
- **`Task2.cpp`**: Checks whether a user-entered number is even or odd using a function.
- **`ALI practice.cpp`**: Even and odd number checker using a function with custom return values.
- **`Untitled1kfkndknf.cpp`**: Compact version of the custom return value even/odd number checker.
- **`Untitled1.cpp`**: C++ starter boilerplate file.
- **`Uzair Arslan Class # 1.cpp`**: Practice on for-loops, while-loops, and core C++ conceptual notes.
- **`OOP Lab Class 2.cpp`**: Introduction to encapsulation, class structure, public/private access specifiers, and getter/setter methods.
- **`Personal Practice # 1 (25-10-26).cpp`**: Multi-class structure (`StudentInfo`, `student_gender`, `exam_marks`) with encapsulation, accessors, and marks validation.
- **`Personal Practice # 1 (26-10-26).cpp`**: Getter and setter methods implementation for private member encapsulation in an age class.
- **`27-10-26 Practice Constructor (Default + Parameterizes).cpp`**: Practice on class member functions, accessor methods, and conceptual notes on constructors and constructor overloading.
